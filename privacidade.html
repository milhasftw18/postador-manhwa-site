Política de Privacidade

Postador Manhwa · Última atualização: 18 de outubro de 2026

1. Quem somos

O Postador Manhwa é uma ferramenta interna, usada só pelos donos dos canais do YouTube em que ele publica. Contato: milhasftw18@gmail.com.

2. Serviços de API do YouTube

O Postador Manhwa usa os Serviços de API do YouTube (YouTube API Services). Ao usar o app, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

3. Dados que o app acessa

Só com a sua autorização, o app acessa:

  • YouTube: para enviar vídeos, thumbnails e legendas ao canal que você autorizou.
  • Google Drive, somente leitura: para ler as pastas e os arquivos dos vídeos.
  • Google Sheets: para ler a planilha de controle e registrar nela o que foi postado.

O app não pede acesso a e-mails, contatos ou outros serviços da sua conta.

4. Como usamos os dados

  • Só para publicar os vídeos nos canais dos próprios donos e registrar o que foi postado.
  • As thumbnails, a descrição e a legenda de cada vídeo são enviadas à API Gemini, do Google, para escolher a thumbnail e criar o título.
  • Não vendemos dados, não os usamos para publicidade e não os compartilhamos com outras pessoas ou empresas, além do uso dos serviços do Google descrito acima.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Armazenamento

  • As credenciais de acesso (tokens) ficam guardadas no servidor do projeto, com acesso restrito.
  • Os arquivos de vídeo baixados ficam no servidor só durante o envio e são apagados depois.

6. Como revogar o acesso

Você pode revogar o acesso do app a qualquer momento nas configurações de segurança da sua Conta do Google. Quando o acesso é revogado, apagamos os dados ligados a ele. Também é possível pedir a exclusão pelo e-mail de contato.

7. Mudanças nesta política

Se o app passar a usar dados de outro jeito, esta página será atualizada antes da mudança.
